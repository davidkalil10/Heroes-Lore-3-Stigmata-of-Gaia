# Diretório `reference/` - Heroes Lore 3 Recomp

Este diretório armazena os snapshots congelados dos projetos anteriores e os artefatos de análise estática do **Heroes Lore 3**:

- `HL4_SNAPSHOT.json` e `hl4_snapshot/`: Snapshot congelado verificável por SHA-256 do `heroes_lore_4_recomp`.
- `HL5_SNAPSHOT.json` e `hl5_snapshot/`: Snapshot congelado verificável por SHA-256 do `heroes_lore_5_recomp`.
- `JAR_PORTS_DOCS.json` e `jar_ports_docs/`: Documentação congelada dos ports J2ME (`HL1`, `HL2`, `Zero`).
- `analysis/`: Relatórios JSON/CSV/Markdown gerados deterministicamente por `tools/inspect_apk.py`.
- `extracted_apk/`: Conteúdo extraído do APK externo (ignorado pelo Git).
- `extracted_ipa/`: Conteúdo extraído de `assets/game.ipa` (ignorado pelo Git).
- `disassembly/`: Dumps e desmontagens auxiliares (ignorado pelo Git).
