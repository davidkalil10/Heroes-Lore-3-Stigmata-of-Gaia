# Objetivo funcional de referência

Itens abaixo são **objetivos futuros**, não funcionalidades já implementadas.

| Área | Comportamento esperado |
| --- | --- |
| Jogo | Campanha, menus, mapas, combate, áudio e saves executando corretamente |
| Vídeo | Native, Wide e Auto; Auto padrão; expansão de cenário e proporções preservadas |
| Idioma | PT-BR padrão e inglês, mudança imediata inclusive em menus/diálogos abertos |
| Interface | Opções do port dentro das opções originais; F10/R3; boa escala no celular |
| Controles | Teclado, toque e gamepad; Switch segue A/B e X/Y impressos; mapear todas as ações reais do HL4 |
| Atualizador | Ao abrir e manual, progresso real, validação/rollback, identidade e assinatura próprias |
| Cloud saves | Backup Google Drive entre plataformas, isolado por jogo, restore retornando ao título |
| Distribuição | Windows portátil, Linux AppImage, Android ARM64/universal conforme viabilidade, Switch NRO |
| Documentação | README de apresentação detalhado, comandos reproduzíveis, decisões e handoff por sessão |

HL5 usa # para trocar fileira; só mapear uma função equivalente no HL4 depois de
confirmar que ela existe. Não inventar input do jogo com base em outro título.
A escolha de OAuth/app IDs/repositório e a autorização de serviços externos
devem ser resolvidas na etapa correspondente; não impedem a pesquisa offline atual.
