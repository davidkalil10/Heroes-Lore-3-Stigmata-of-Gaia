# Sessão 20 - 2026-11-14 (`S12` Fase 1: Migração Completa do Runtime PC para C++17 Estático)

## Objetivo
Concluir a Fase 1 da migração nativa em C++17 para PC Windows x64 com paridade completa em relação ao runtime Python v1.0.3 (`Mach-O + ObjC + HLE + OpenGL + Áudio + Input/Foco 2D + Live EN/PT-BR + About Credits + Cloud Save Google Drive + OTA GitHub Releases`), antes de avançar para Linux, Android ARM64, Nintendo Switch e GitHub Actions.

## Entregas e Descobertas Técnicas
1. **Engine & HLE C++17 (`CMakeLists.txt`, `src/core/`, `src/hle/`, `src/audio/`)**:
   - Runtime Mach-O ARMv6 (`zip_archive`, `bundle`, `macho_loader`, `machine` + Unicorn ARM1176 + watchdog persistente, `objc`, `runtime` + `flush_open_files()`).
   - Shims completos em C++ para `libc`, `Foundation`, `UIKit`, `EAGLContext`, `GLBridge` (projeção ortográfica True Widescreen e texturas `.pvr`), e `AudioMixer` (`dr_mp3` + OpenAL fora do callback SDL).
   - Solução portável em `CMakeLists.txt` (`hl3_replace_in_file`) renomeando `crc32(` interno do Unicorn (`crc32c.h`, `crc32c.c`, `helper.c`, `helper-a64.c`) para `uc_qemu_crc32(` de forma a evitar colisão de símbolos com `zlib::crc32` quando `png_codec.cpp` aciona `deflate()`.
2. **Serviços de Plataforma & UI Nativos (`src/platform/`, `src/main.cpp`, `assets/hl3.rc`)**:
   - `DisplayConfig`, `I18n` (inglês padrão + PT-BR ao vivo), `NetHttp` (WinHTTP TLS nativo), `PngCodec`, `UiRenderer` (`stb_truetype.h` OSD + botão ribbon prateado/azul), `OptionsModal` (6 páginas responsivas), `CloudSaveManager` (Google Drive OAuth Device Flow + Drive v3), `UpdateManager` (GitHub Releases + script staging `.ps1`), e `InputController` (5 etapas + foco 2D + injeção de créditos `6632` + reload ao vivo de `TextUtils` e banner).
   - Corrigida truncagem silenciosa `u16 -> u32` no tipo `cid` em `UiNode`, `InjectedButtonSpec`, `focus_cid_`, `is_cancel_cid` e `make_virtual_port_btn` para os botões virtuais `99003` e `99113`.
   - `tools/bump_version.py` atualizado para sincronizar também `kPortVersion` em `src/core/common.h`.
3. **Empacotamento Standalone C++ (`tools/build_pc_cpp.py`)**:
   - Compilação estática MSYS2 UCRT64 (`-static -static-libgcc -static-libstdc++`, `DllCharacteristics = 0x0160` sem CFG, zero DLLs MinGW/SDL/zlib externas) reduzida após `strip -s` para `HeroesLore3.exe` (`6.703.104` bytes).
   - Gerado `dist/heroes_lore_3_windows_x64.zip` (`45.473.958` bytes, 24 entradas limpas, embarcando apenas `assets/game.ipa` verificado por SHA-256 sem `.apk` redundante).
